# Шахматная песочница — интерактивная доска для тренеров

## 🎯 Описание
Интерактивная шахматная доска для онлайн- и офлайн-обучения. Создавайте любые позиции, играйте с учеником удалённо или на одном устройстве.

## ✨ Возможности
- 🏠 **Локальная игра** — два игрока на одном устройстве
- 🌐 **Онлайн-игра** — тренер и ученик на разных устройствах (Firebase)
- 🖱️ **Drag & Drop** — перетаскивайте фигуры мышкой или пальцем
- 💡 **Подсветка ходов** — возможные ходы и взятия подсвечиваются
- 👑 **Превращение пешки** — выбор фигуры при достижении последней линии
- 🏰 **Рокировка и взятие на проходе** — полные шахматные правила
- 📜 **История партии** — просмотр и возврат к любому ходу
- 🎯 **Выбор первого хода** — белые или чёрные
- 🌍 **Двуязычный интерфейс** — русский / английский
- 📱 **Адаптивный дизайн** — работает на ПК и мобильных устройствах

## 🚀 Как играть

### Локальная игра
1. Выберите режим **«Локально»**
2. Расставьте фигуры перетаскиванием из палитры
3. Выберите, кто ходит первым
4. Нажмите **«СТАРТ»**
5. Играйте по очереди

### Онлайн-игра (тренер + ученик)
**Тренер:**
1. Нажмите **«Онлайн»** → **«Создать»**
2. Скопируйте код комнаты и отправьте ученику
3. Нажмите **«СТАРТ»**

**Ученик:**
1. Нажмите **«Онлайн»**
2. Введите код комнаты → **«Войти»**
3. Ждите, пока тренер начнёт игру

## 🎮 Управление
- **Перетаскивание** — захватите фигуру и переместите на нужную клетку
- **Клик** — выберите фигуру, затем кликните на целевую клетку
- **Кнопки** — Старт, Новая партия, Отмена, Сброс, Очистить доску

## 🔧 Технологии
- HTML5 / CSS3 / JavaScript
- Firebase Realtime Database (онлайн-режим)
- Адаптивная вёрстка

## 📱 Системные требования
- Любой современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет для онлайн-режима

# Chess Sandbox — Interactive Board for Trainers

## 🎯 Description
Interactive chess board for online and offline training. Create any positions, play with a student remotely or on one device.

## ✨ Features
- 🏠 **Local game** — two players on one device
- 🌐 **Online game** — trainer and student on different devices (Firebase)
- 🖱️ **Drag & Drop** — move pieces with mouse or finger
- 💡 **Move highlighting** — possible moves and captures are highlighted
- 👑 **Pawn promotion** — choose a piece when reaching the last rank
- 🏰 **Castling & En passant** — full chess rules
- 📜 **Game history** — view and return to any move
- 🎯 **First move selection** — white or black
- 🌍 **Bilingual interface** — Russian / English
- 📱 **Responsive design** — works on PC and mobile devices

## 🚀 How to Play

### Local Game
1. Select **"Local"** mode
2. Set up pieces by dragging from the palette
3. Choose who moves first
4. Press **"START"**
5. Take turns playing

### Online Game (Trainer + Student)
**Trainer:**
1. Click **"Online"** → **"Create"**
2. Copy the room code and send it to the student
3. Press **"START"**

**Student:**
1. Click **"Online"**
2. Enter the room code → **"Join"**
3. Wait for the trainer to start the game

## 🎮 Controls
- **Drag & Drop** — grab a piece and move it to the desired square
- **Click** — select a piece, then click on the target square
- **Buttons** — Start, New Game, Undo, Reset, Clear Board

## 🔧 Technologies
- HTML5 / CSS3 / JavaScript
- Firebase Realtime Database (online mode)
- Responsive layout

## 📱 System Requirements
- Any modern browser (Chrome, Firefox, Safari, Edge)
- Internet connection for online mode
